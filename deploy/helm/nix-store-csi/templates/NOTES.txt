The node plugin runs privileged. If {{ .Release.Namespace }} enforces a Pod Security
level, it has to allow privileged pods:

  kubectl label namespace {{ .Release.Namespace }} pod-security.kubernetes.io/enforce=privileged

Pods mount the closures of store paths with an inline volume:

  volumes:
    - name: nix
      csi:
        driver: nix-store-csi
        readOnly: true
        volumeAttributes:
          storePaths: /nix/store/<hash>-hello-2.12.3
{{- if not .Values.admissionPolicy.allowedNamespaces }}

Pods in every namespace can use these volumes, and through them any private
cache that the plugin has credentials for. To allow the volumes only in some
namespaces, set admissionPolicy.allowedNamespaces.
{{- end }}
{{- if .Values.metrics.enabled }}

The node plugins hold a prefetch list once this Prometheus query returns
nothing:

  nix_store_csi_build_info{system="<system>"{{ if .Values.nodePools }}, pool="<pool>"{{ end }}} unless on (instance) nix_store_csi_prefetched{list="<name>", hash="<hash>"} == 1

<name> is the key's name after the system, empty for storePaths.<system> and
storePaths. For storePaths, select the systems without keys of their own.
<hash> is the first 12 hex digits of the SHA-256 of the key's value in its
ConfigMap, {{ .Release.Name }}-prefetch{{ if .Values.nodePools }}[-<pool>]{{ end }} or the one that prefetchConfigMap names:

  kubectl -n {{ .Release.Namespace }} get configmap <configmap> \
    -o jsonpath='{.data.storePaths\.<system>\.<name>}' | sha256sum | head -c 12
{{- if and .Values.nodePools (not .Values.metrics.podMonitor.enabled) }}

The pool label needs metrics.podMonitor.enabled, or a scrape config of your
own that copies the nix-store-csi/pool label of the node plugins' pods.
{{- end }}
{{- end }}
{{- if .Values.locality.enabled }}

The locality extender serves kube-scheduler at /prioritize and Volcano at
/volcano/prioritize, on port {{ .Values.locality.port }} of the Service {{ .Release.Name }}-locality.
kube-scheduler usually runs without cluster DNS, so give it the Service's
cluster IP:

  kubectl -n {{ .Release.Namespace }} get service {{ .Release.Name }}-locality -o jsonpath='{.spec.clusterIP}'
{{- end }}
