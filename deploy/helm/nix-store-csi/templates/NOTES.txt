The node plugin runs privileged. If {{ .Release.Namespace }} enforces a Pod Security
level, it has to allow privileged pods:

  kubectl label namespace {{ .Release.Namespace }} pod-security.kubernetes.io/enforce=privileged

Pods mount the closures of store paths with an inline volume:

  volumes:
    - name: nix
      csi:
        driver: nix-store-csi
        readOnly: true
        volumeAttributes:
          storePaths: /nix/store/<hash>-hello-2.12.3
{{- if not .Values.admissionPolicy.allowedNamespaces }}

Pods in every namespace can use these volumes, and through them any private
cache that the plugin has credentials for. To allow the volumes only in some
namespaces, set admissionPolicy.allowedNamespaces.
{{- end }}
